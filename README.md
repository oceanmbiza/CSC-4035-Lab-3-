## Page Descriptions
- **Home Page (index.html):**  
  Displays a hero banner with a welcome message and two side-by-side feature sections arranged using Flexbox.
- **Services Page (services.html):**  
  Showcases at least four service cards, each containing a heading, descriptive text, and an image or icon. The cards are arranged in a responsive layout using CSS Grid with hover effects applied to enhance interactivity.

- **Contact Page (contact.html):**  
  Contains a styled HTML5 contact form with fields for name, email, subject, and message. The form uses HTML5 validation, responsive styling via CSS, and includes subtle animations on button hover and input focus.

## Summary of Features Used
- **CSS Selectors:**  
  Utilized element selectors, class selectors, and pseudo-classes (like :hover and :focus) to target and style components effectively.

- **Flexbox:**  
  Implemented in the navigation bar and the home page feature sections for a responsive and adaptive layout.

- **CSS Grid:**  
  Employed on the services page to create a flexible grid layout for service cards, ensuring a consistent and responsive design.

- **Media Queries:**  
  Added breakpoints at max-widths of 1024px, 768px, and 480px to adapt the layout for various device sizes, including toggling the navigation menu into a hamburger style on smaller screens.

- **Animations:**  
  Integrated CSS keyframes for fade-in effects on page content and smooth transitions on hover/focus states to enhance user experience.
